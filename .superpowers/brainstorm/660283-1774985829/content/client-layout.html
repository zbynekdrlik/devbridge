Does this client dashboard layout look right? The key points:

  • Large timestamp + "ago" on the left — the most prominent element
  • Status pill colored by state (green/red/blue) with colored card border
  • Audit timeline always visible — no collapse/expand, no state lost on refresh
  • Job ID tiny at the bottom — barely visible unless you look for it
  • Failed jobs get red border + red timestamp, showing exactly where it broke
  • In-progress jobs get blue border with ⏳ on the last step
